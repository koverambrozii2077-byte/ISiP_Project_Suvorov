# 1. Предметная область
Предметная область: оказание телекоммуникационных услуг абонентам.
Компания подключает клиентов к услугам связи, при необходимости устанавливает оборудование, ведёт лицевые счета, принимает авансовые платежи, фиксирует факты оказания услуг, списывает средства, формирует отчёты для абонентов, налоговых органов и органов государственной статистики.

# 2. Название информационной системы
ИС «Телеком-Биллинг» — информационная система учёта абонентов, телекоммуникационных услуг, оборудования, платежей и биллинга.
